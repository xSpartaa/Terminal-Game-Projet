# Terminal-Game-Projet
# CONSOLE GAME SUITE - JAVA PROJECT (L2 CS)DESCRIPTION:

# DESCRIPTION :

This project is a Java-based console application featuring classic board games. <br>
It was developed as part of a second-year Computer Science (L2) curriculum to <br>
demonstrate mastery of Object-Oriented Programming (OOP) principles and the <br>
Model-View-Controller (MVC) architectural pattern. <br>

# INCLUDED GAMES:
• Tic-Tac-Toe (Morpion): A classic game played on a 3x3 grid. <br>
• Connect 4 (Puissance 4): A strategic game where players align 4 tokens on a <br>
vertical grid. <br>

# PROJECT STRUCTURE (MVC Architecture):
• Main: Entry point of the application. <br>
• Controller (src/controleur/): Orchestrates the game flow and links the Model and the View. <br>
• Model (src/modele/): <br>
- Jeu.java: Abstract base class defining common game structures. <br>
- Morpion.java & Puissance4.java: Specific game rule implementations. <br>
- Joueur.java: Management of player entities. <br> 

• View (src/vue/): <br>
- Ihm.java: Handles all console-based user inputs and outputs. <br>

# TECHNICAL FEATURES:
Full implementation of inheritance and polymorphism.  <br>
Modular design allowing for easy addition of new grid-based games. <br>
Efficient game loop management. <br>
Version control using Git.REQUIREMENTS:Java Development Kit (JDK) 8 or higher. <br>
Terminal or any Java IDE. <br>
